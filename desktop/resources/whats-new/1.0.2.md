- **Check-in on the iPad opens when you start.** Start check-in and Reopen check-in now open check-in on the iPad until half an hour after the workshop ends, even if an earlier window had run out. A new panel shows whether the iPad accepts check-ins, with Open check-in, +30 min and Close now.
- **Newer booking exports update the register.** Importing a newer booking spreadsheet can now update the booking status of people already in the register, matched by email, including cancellations: tick *Update booking status* in the preview. The preview shows the changes before anything is written; check-ins are never changed.
- **The window opens again.** On some Macs AttendWell 1.0.0 started without showing its window. It now always appears, and clicking the Dock icon brings it back.
- **Test connection.** Settings → Connection → Test connection checks whether the check-in address reaches this laptop.
